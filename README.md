# ScRl — школьная экономика

ScRl — серверное приложение школьной экономики на чистом Node.js, без внешних npm-зависимостей.

## Запуск

Требуется Node.js 18 или новее.

```bash
npm start
```

По умолчанию приложение доступно по адресу http://localhost:3000. Порт можно изменить переменной окружения `PORT`.

Проверка синтаксиса всех JavaScript-модулей:

```bash
npm run check
```

## Структура проекта

- `scrl.js` — точка входа, сохраняет привычную команду запуска.
- `src/server.js` — HTTP-сервер и маршрутизация.
- `src/config.js` — настройки и путь к данным.
- `src/store.js` — начальные данные, хранилище, счета и транзакции.
- `src/security.js` — хеширование паролей.
- `src/session.js` — сессии, роли и возрастные ограничения.
- `src/utils/http.js` — общие HTTP/HTML-функции.
- `src/views/` — общий макет, стили и flash-сообщения.
- `src/features/` — функциональные модули авторизации, ученического кабинета, маркета и заказов, аукционов, биржи, учительского и административного кабинетов.

Данные остаются в корневом файле `scrl-data.json`. Этот файл не добавляется в Git.

## Сохранение функциональности

В рефакторинге исходные страницы, обработчики, правила экономики, формы, URL-маршруты и формат данных не намеренно не меняются. Внешние зависимости не добавлены.
